A coluna "Estado atual" descreve o que o código **realmente faz** hoje (verificado no código e, onde indicado, em execução no preview local com dados sintéticos). Nada foi validado em staging ou produção.

## Alteração proposta para B (não aplicada)

Em `db/migrations/0026_identity_foundation.sql` (bloco `MIGRATION_ONLY`), trocar a regra "1 admin ⇒ owner" por "≥ 1 admin sem designação ⇒ abortar":

- `IF admin_count >= 1 AND designated IS NULL THEN RAISE EXCEPTION 'Migração abortada: …Designe o Platform Owner explicitamente…'`
- se `admin_count >= 1`, o designado precisa ser um admin ativo; `chosen := designated`; os demais viram usuários comuns (como hoje).
- `db/legacyPreflight.ts` (verificação da 0026): `HAVING count(*) > 1` passa a `>= 1` na parte dos administradores.

**Impactos:** (1) todo ambiente com algum admin legado precisa de `PGOPTIONS="-c levora.platform_owner_user_id=<id>"` ou de `PGOPTIONS` equivalente no preflight e no runner; (2) `test/schemaMigrationsData.test.ts` (baseline com 1 admin, usuário 3) e `test/identityMigration.test.ts` passam a precisar da designação; (3) banco novo (instalação por `schema.sql`) não é afetado; (4) nenhum banco com a 0026 já aplicada é afetado (a migration não roda de novo). **Não atribuir o owner a nenhum dos IDs reais do banco de desenvolvimento (1, 18, 63) sem autorização.**

## Mudança proposta para C (não aplicada)

No ramo de cadastro de `src/helpers/oauthCallback.tsx`: recusar com motivo `email_nao_verificado` quando `identity.emailVerified !== true`. Efeitos: o cadastro pelo Google exige e-mail verificado; o cadastro pela Microsoft fica indisponível (`emailVerified` é sempre `false`, pois o token não traz evidência) até haver verificação pela aplicação; o login por identidade já vinculada **não muda**. Os testes `googleAuth`/`microsoftAuth` que hoje afirmam "cadastro grava `emailVerified=false`" precisariam mudar. **Dependência para reabrir a Microsoft:** fluxo de verificação do endereço pela aplicação (token de uso único por e-mail), que depende do SMTP configurado, e qualificação real com credenciais próprias (continua **não qualificada para produção**).
